# saju8z

생년월일시로 사주팔자와 십성을 계산하고, 시간을 모르면 삼주(년·월·일)를 제공하는 만세력 CLI 라이브러리입니다. 

양력/음력/윤달을 지원하고, 결과를 텍스트/JSON/AI 전달용 프롬프트로 출력합니다.

**Node.js 22 이상과 npm**이 필요합니다. 터미널에서 바로 사용하려면 `--date`·`--time` 또는 `--dt`를 본인의 생년월일시로 바꾸세요.



## CLI 빠른 시작

### 바로 실행하고 결과 보기

전역 설치 없이 한 줄로 실행합니다. 아래 예시는 양력 2000년 2월 23일 00시 10분, 현재 GMT 기준입니다.

```sh
npx --yes saju8z --date 2000-02-25 --time 04:10
```

### 전역 설치 후 실행

```sh
npm install -g saju8z
saju8z --date 2000-02-25 --time 04:10
```



### 인자 없이 실행하고 날짜·시각 입력하기

옵션 없이 `saju8z`를 실행하면 생년월일과 출생 시각을 차례로 질문합니다. 아래처럼 값을 입력한 뒤 각각 Enter를 누르세요.

```sh
saju8z
```

입력 예시:

```text
생년월일과 출생 시각을 입력하세요. 양력·현재 GMT 시차로 계산합니다.
생년월일 (YYYY-MM-DD, 예: 1998-03-05): 1998-03-05
출생 시각 (HH:mm, 예: 11:00 / 시간을 모르면 비워두고 Enter): 11:00

[만세력]
...
```

- 날짜는 `1998-03-05`처럼 연도 4자리·월 2자리·일 2자리를 하이픈으로 구분합니다.
- 시각은 `11:00`처럼 24시간제의 시·분을 콜론으로 구분합니다. 오후 11시는 `23:00`, 자정은 `00:00`입니다.
- 시간을 모르면 시각 질문에서 아무것도 적지 않고 Enter를 누르세요. 삼주만 출력합니다.
- 시간을 입력하면 **양력·실행 환경의 현재 GMT 시차·기본 텍스트 형식**으로 사주를 출력합니다. 시간을 생략하면 양력 날짜 기준으로 계산하며 GMT 환산과 -30분 보정은 생략합니다.
- 잘못된 날짜·시각이나 빈 날짜는 오류로 종료합니다. 빈 시각은 시간 미상으로 처리합니다. 다시 실행해 입력하세요. 음력·윤달·고정 시차·다른 출력 형식은 아래 CLI 옵션을 사용하세요.

대화형 입력은 **인자가 전혀 없을 때만** 시작합니다. 옵션을 전달하면 `--date` 또는 `--dt`가 필요하며, `--time`은 선택입니다. 입력 안내는 표준 오류(stderr), 계산 결과는 표준 출력(stdout)에 기록합니다.

### 날짜와 시각을 한 번에 입력하기

`--dt`는 날짜만 적는 **`YYYYMMDD` 8자리**와 시각까지 적는 **`YYYYMMDDHHmm` 12자리**를 지원합니다. `19980305`는 `--date 1998-03-05`와 같으며 삼주를 출력합니다. `199803051100`은 `--date 1998-03-05 --time 11:00`과 같은 사주를 출력합니다.

```sh
saju8z --dt 19980305
saju8z --dt 199803051100
saju8z --dt 199803051100 --gmt +09:00 --format json
saju8z --dt=199803051100 --gmt +09:00 --format prompt
```

**옵션으로 실행할 때는 `--date` 또는 `--dt`를 입력해야 합니다. `--time`은 선택입니다.** `--dt`와 `--date`·`--time`을 혼용하면 오류가 발생합니다. 월·일·시·분은 각각 두 자리로 입력하며, 날짜와 시각의 유효성 검사는 기존 입력 방식과 같습니다. 시간이 있으면 `--gmt` 생략 시 현재 시차를 사용합니다. 시간이 없으면 시차 환산을 생략합니다. `--calendar lunar`·`--leap`는 두 방식 모두 사용할 수 있습니다.

### 음력과 윤달 입력

양력은 기본값입니다. 한국 음력 날짜는 `--calendar lunar`를 추가하고, **음력 윤달이면 `--leap`도 함께** 지정합니다. 날짜와 출생 시각은 선택한 달력과 GMT 기준으로 입력합니다.

```sh
# 음력 평달 2017년 5월 1일 12:00
npx --yes saju8z --date 2017-05-01 --time 12:00 --gmt +09:00 --calendar lunar

# 음력 윤5월 1일 12:00 → 양력 2017-06-24 12:00과 같은 계산 결과
npx --yes saju8z --date 2017-05-01 --time 12:00 --gmt +09:00 --calendar lunar --leap
```



### CLI 옵션과 시차


| 옵션             | 필수  | 기본값·설명                                                |
| -------------- | --- | ----------------------------------------------------- |
| `--dt`         | 선택 | 날짜 `YYYYMMDD` 8자리 또는 날짜·시각 `YYYYMMDDHHmm` 12자리 |
| `--date`       | 조건부 | 생년월일 `YYYY-MM-DD`. 옵션 실행 시 `--dt`가 없으면 필수                          |
| `--time`       | 아니요 | 출생 시각 `HH:mm`, `00:00`\~`23:59`. 생략하면 삼주 출력 |
| `--gmt`        | 아니요 | 고정 시차 `±HH:mm`, `-12:00`\~`+14:00` 기본값은 실행 환경의 현재 GMT |
| `--calendar`   | 아니요 | `solar`(기본, 양력) 또는 `lunar`(한국 음력)                     |
| `--leap`       | 아니요 | 음력 윤달일 때 지정. `--calendar lunar`와 함께 사용                |
| `--format`     | 아니요 | `text`(기본), `json`, `prompt`                          |
| `--help`, `-h` | 아니요 | 도움말 출력                                                |


시차는 `--gmt -05:00` 또는 `--gmt=-05:00`처럼 전달합니다.

`--gmt`를 생략하면 출생일 당시가 아닌 **실행 시점의 GMT 시차**를 사용합니다. 한국 표준시 환경에서는 `+09:00`이며, 서머타임을 사용하는 환경에서는 현재 서머타임도 반영됩니다. 출생 당시 위치의 시차로 계산하려면 해당 시차를 직접 지정하세요. 시간 미상일 때는 `--gmt` 값에 관계없이 날짜 기준 삼주를 계산합니다. 전달한 GMT 값의 형식과 범위는 계속 검증합니다.



## 라이브러리 적용

```js
import { calculateSajuChart, formatSajuChart } from "saju8z";

const result = calculateSajuChart({
  date: "2000-02-29",
  time: "00:10",
  gmt: "+09:00"
});

console.log(result.fourPillars); // 사주팔자 객체
console.log(result.tenGods); // 십성 객체
console.log(formatSajuChart(result, "text")); // 만세력 텍스트 문자열
console.log(formatSajuChart(result, "json")); // JSON 문자열
console.log(formatSajuChart(result, "prompt")); // AI 전달용 프롬프트 문자열
```



시간을 모르면 라이브러리에서도 `time`을 생략하거나 `undefined`로 전달합니다.

```ts
const unknown = calculateSajuChart({ date: "1998-03-05", gmt: "+09:00" });
console.log(unknown.fourPillars.hour); // null
console.log(unknown.normalizedDateTime.hour); // null
console.log(formatSajuChart(unknown)); // 년·월·일 삼주
```

시간을 명시한 호출은 `SajuChartResultWithTime`, 생략한 호출은 `SajuChartResultWithoutTime`으로 추론됩니다. `SajuChartResult`는 두 결과의 유니온입니다. `time`이 선택적인 `SajuChartInput` 변수를 전달하면 결과도 유니온이므로 시주를 사용하기 전에 `null`을 확인하세요. 두 결과 타입은 `saju8z`와 `saju8z/format`에서 가져올 수 있습니다. 저수준 `saju8z/core`의 기존 사주 타입과 함수는 그대로 사용합니다.

## 입력

`calculateSajuChart(input)`은 다음 객체를 받습니다.


| 필드          | 타입                   | 필수  | 설명                                         |
| ----------- | -------------------- | --- | ------------------------------------------ |
| `date`      | `string`             | 예   | `YYYY-MM-DD`. 선택한 달력 기준의 날짜                |
| `time`      | `string`             | 아니요 | `HH:mm`, `00:00`\~`23:59`. 생략 또는 `undefined`이면 시간 미상 |
| `gmt`       | `string`             | 예   | 부호를 포함한 고정 시차 `±HH:mm`, `-12:00`\~`+14:00` |
| `calendar`  | `"solar"`, `"lunar"` | 아니요 | 양력 또는 한국 음력. 기본값 `"solar"`                 |
| `leapMonth` | `boolean`            | 아니요 | 음력 윤달 여부. 기본값 `false`, 음력에서만 `true` 허용     |


라이브러리 API의 `gmt`는 출생 당시 날짜·시간의 시차를 직접 지정합니다. 예를 들어 한국 표준시는 `+09:00`, UTC는 `+00:00`입니다. 실행 환경의 시간대나 지역 이름으로 자동 추정하지 않습니다. `gmt`는 시간 미상 입력에서도 필수이며 형식을 검증하지만, 날짜 기준 계산에는 사용하지 않습니다. `time: ""`·`time: null`은 허용하지 않습니다. CLI에서도 `--time` 값을 비우는 대신 옵션을 생략하고, 대화형 질문에서만 빈 시각을 허용합니다.

음력 윤달은 다음과 같이 입력합니다.

```js
const result = calculateSajuChart({
  date: "2017-05-01",
  time: "12:00",
  gmt: "+09:00",
  calendar: "lunar",
  leapMonth: true
});
// 양력 2017-06-24 12:00, GMT+09:00 입력과 같은 결과
```



## 결과와 출력 형식

`calculateSajuChart`는 JSON으로 직렬화 가능한 `SajuChartResult` 객체를 반환합니다.


| 필드                    | 내용                                                                                                    |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| `normalizedDateTime`  | 시간이 있으면 GMT+09:00으로 환산한 양력 시각. 시간이 없으면 양력 날짜와 `hour: null`, `minute: null`                                        |
| `calculationDateTime` | 시간이 있으면 -30분 보정한 시각. 시간이 없으면 `normalizedDateTime`과 동일한 날짜·null 시각                                                                             |
| `fourPillars`         | `year`, `month`, `day`, `hour`의 사주팔자. 시간이 없으면 `hour: null`                                         |
| `tenGods`             | 일간 기준 십성. `yearStem`, `yearBranch`, `monthStem`, `monthBranch`, `dayBranch`, `hourStem`, `hourBranch`. 시간 미상이면 마지막 두 필드는 `null` |


천간·지지·십성은 `"병"`, `"진"`, `"식신"`과 같은 한국어 문자열입니다. 일간 자체의 십성 필드는 없으며, 만세력 텍스트에서는 `본원`으로 표시합니다.

## 계산 기준과 지원 범위

시간을 입력한 경우 기존 계산 기준을 적용합니다.

1. 음력이면 양력으로 변환합니다.
2. 입력 GMT에서 GMT+09:00으로 환산합니다.
3. -30분을 보정한 시각으로 사주팔자를 계산합니다.

시간을 생략한 경우 음력 변환만 수행하고, 시차 환산과 -30분 보정 없이 해당 양력 날짜로 삼주를 계산합니다. 입춘·절입 당일부터 새 년주·월주를 적용하고 일주는 입력 날짜 기준입니다. 임의의 자정·정오를 출생 시각으로 대입하지 않습니다.

시간을 입력한 경우 년주는 입춘, 월주는 프로젝트의 고정 절입 시각 표, 일주는 자정을 기준으로 합니다. 고정 절입 표는 실제 연도별 천문 절기 시각과 차이가 있을 수 있습니다. 서머타임·역사적 시차·출생지 경도 보정은 자동 적용하지 않습니다.

양력 입력과 GMT+09:00 환산 날짜는 1900~2100년을 지원합니다. 음력은 1900년부터 음력 2050년 11월 18일까지의 유효 날짜를 지원합니다. 시간을 입력하면 -30분 보정으로 1900년 첫날이 전년 말로 이동할 수 있습니다. 시간이 없으면 해당 날짜를 보존합니다.

성별 입력은 필요하지 않습니다. 대운·세운·운세·성격 해석 기능은 제공하지 않습니다.
