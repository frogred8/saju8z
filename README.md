# saju8z

생년월일시로 사주팔자와 십성을 계산하는 만세력 CLI 라이브러리입니다. 

양력/음력/윤달을 지원하고, 결과를 텍스트/JSON/AI 전달용 프롬프트로 출력합니다.

**Node.js 22 이상과 npm**이 필요합니다. 터미널에서 바로 사용하려면 `--date`, `--time`을 본인의 생년월일시로 바꾸세요.



## CLI 빠른 시작

### 바로 실행하고 결과 보기

전역 설치 없이 한 줄로 실행합니다. 아래 예시는 양력 2000년 2월 23일 00시 10분, 현재 GMT 기준입니다.

```sh
npx --yes saju8z --date 2000-02-25 --time 04:10
```

### 전역 설치 후 실행

```sh
npm install -g saju8z
saju8z --date 2000-02-25 --time 04:10
```

### 음력과 윤달 입력

양력은 기본값입니다. 한국 음력 날짜는 `--calendar lunar`를 추가하고, **음력 윤달이면 `--leap`도 함께** 지정합니다. 날짜와 출생 시각은 선택한 달력과 GMT 기준으로 입력합니다.

```sh
# 음력 평달 2017년 5월 1일 12:00
npx --yes saju8z --date 2017-05-01 --time 12:00 --gmt +09:00 --calendar lunar

# 음력 윤5월 1일 12:00 → 양력 2017-06-24 12:00과 같은 계산 결과
npx --yes saju8z --date 2017-05-01 --time 12:00 --gmt +09:00 --calendar lunar --leap
```



### CLI 옵션과 시차


| 옵션             | 필수  | 기본값·설명                                                |
| -------------- | --- | ----------------------------------------------------- |
| `--date`       | 예   | 생년월일 `YYYY-MM-DD`. 월·일은 두 자리                          |
| `--time`       | 예   | 출생 시각 `HH:mm`, `00:00`\~`23:59`. 초는 지원하지 않음         |
| `--gmt`        | 아니요 | 고정 시차 `±HH:mm`, `-12:00`\~`+14:00` 기본값은 실행 환경의 현재 GMT |
| `--calendar`   | 아니요 | `solar`(기본, 양력) 또는 `lunar`(한국 음력)                     |
| `--leap`       | 아니요 | 음력 윤달일 때 지정. `--calendar lunar`와 함께 사용                |
| `--format`     | 아니요 | `text`(기본), `json`, `prompt`                          |
| `--help`, `-h` | 아니요 | 도움말 출력                                                |


시차는 `--gmt -05:00` 또는 `--gmt=-05:00`처럼 전달합니다.

`--gmt`를 생략하면 출생일 당시가 아닌 **실행 시점의 GMT 시차**를 사용합니다. 한국 표준시 환경에서는 `+09:00`이며, 서머타임을 사용하는 환경에서는 현재 서머타임도 반영됩니다. 출생 당시 위치의 시차로 계산하려면 해당 시차를 직접 지정하세요.



## 라이브러리 적용

```js
import { calculateSajuChart, formatSajuChart } from "saju8z";

const result = calculateSajuChart({
  date: "2000-02-29",
  time: "00:10",
  gmt: "+09:00"
});

console.log(result.fourPillars); // 사주팔자 객체
console.log(result.tenGods); // 십성 객체
console.log(formatSajuChart(result, "text")); // 만세력 텍스트 문자열
console.log(formatSajuChart(result, "json")); // JSON 문자열
console.log(formatSajuChart(result, "prompt")); // AI 전달용 프롬프트 문자열
```



## 입력

`calculateSajuChart(input)`은 다음 객체를 받습니다.


| 필드          | 타입                   | 필수  | 설명                                         |
| ----------- | -------------------- | --- | ------------------------------------------ |
| `date`      | `string`             | 예   | `YYYY-MM-DD`. 선택한 달력 기준의 날짜                |
| `time`      | `string`             | 예   | `HH:mm`, `00:00`\~`23:59`. 초는 지원하지 않음      |
| `gmt`       | `string`             | 예   | 부호를 포함한 고정 시차 `±HH:mm`, `-12:00`\~`+14:00` |
| `calendar`  | `"solar"`, `"lunar"` | 아니요 | 양력 또는 한국 음력. 기본값 `"solar"`                 |
| `leapMonth` | `boolean`            | 아니요 | 음력 윤달 여부. 기본값 `false`, 음력에서만 `true` 허용     |


라이브러리 API의 `gmt`는 출생 당시 날짜·시간의 시차를 직접 지정합니다. 예를 들어 한국 표준시는 `+09:00`, UTC는 `+00:00`입니다. 실행 환경의 시간대나 지역 이름으로 자동 추정하지 않습니다.

음력 윤달은 다음과 같이 입력합니다.

```js
const result = calculateSajuChart({
  date: "2017-05-01",
  time: "12:00",
  gmt: "+09:00",
  calendar: "lunar",
  leapMonth: true
});
// 양력 2017-06-24 12:00, GMT+09:00 입력과 같은 결과
```



## 결과와 출력 형식

`calculateSajuChart`는 JSON으로 직렬화 가능한 `SajuChartResult` 객체를 반환합니다.


| 필드                    | 내용                                                                                                    |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| `normalizedDateTime`  | 양력으로 변환하고 GMT+09:00으로 환산한 `{ year, month, day, hour, minute }`                                        |
| `calculationDateTime` | 환산 시각에 -30분 보정을 적용한 계산 시각                                                                             |
| `fourPillars`         | `year`, `month`, `day`, `hour`의 사주팔자. 각 값은 `{ stem, branch }`                                         |
| `tenGods`             | 일간 기준 십성. `yearStem`, `yearBranch`, `monthStem`, `monthBranch`, `dayBranch`, `hourStem`, `hourBranch` |


천간·지지·십성은 `"병"`, `"진"`, `"식신"`과 같은 한국어 문자열입니다. 일간 자체의 십성 필드는 없으며, 만세력 텍스트에서는 `본원`으로 표시합니다.

일반적인 만세력 계산에는 `saju8z`를 사용합니다. 저수준 함수는 입력 검증과 보정 적용 방식을 호출자가 확인해야 합니다.



## 계산 기준과 지원 범위

1. 음력이면 양력으로 변환합니다.
2. 입력 GMT에서 GMT+09:00으로 환산합니다.
3. -30분을 보정한 시각으로 사주팔자를 계산합니다.

년주는 입춘, 월주는 프로젝트의 고정 절입 시각 표, 일주는 자정을 기준으로 합니다. 고정 절입 표는 실제 연도별 천문 절기 시각과 차이가 있을 수 있습니다. 서머타임·역사적 시차·출생지 경도 보정은 자동 적용하지 않습니다.

양력 입력과 GMT+09:00 환산 날짜는 1900~2100년을 지원합니다. 음력은 1900년부터 음력 2050년 11월 18일까지의 유효 날짜를 지원합니다. -30분 보정으로 1900년 첫날이 전년 말로 이동할 수 있습니다.

성별 입력은 필요하지 않습니다. 대운·세운·운세·성격 해석 기능은 제공하지 않습니다.
