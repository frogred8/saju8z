# saju8z 사주 계산

`npx --yes saju8z` CLI로 명식을 계산한다. 사주 계산 규칙을 직접 재구현하거나 결과를 추측하지 않는다.

## 입력 처리

- 계산에 필요한 생년월일을 받는다. 날짜 형식이 모호하거나 날짜가 없으면 확인한다.
- 시간은 선택 사항이다. 사용자가 모른다고 하면 시간 입력을 생략하고, 시주를 추정하지 않는다.
- 달력은 양력을 기본으로 한다. 사용자가 음력이라고 하면 `--calendar lunar`를 지정하고, 윤달이라고 확인된 경우에만 `--leap`을 추가한다.
- 사용자가 GMT 오프셋을 주면 `--gmt=±HH:mm`으로 전달한다. 오프셋을 주지 않았으면 다시 묻지 말고 `--gmt`를 생략해 실행 환경의 현재 GMT 오프셋을 사용한다. 이 값이 계산에 사용된 시차임을 결과에 밝힌다. 사용자가 실행 환경과 다른 자신의 현재 GMT 오프셋을 알려주면 그 값을 우선한다.
- 사주는 성별 입력이 필요하지 않다. 별도 요청이 없으면 성별이나 미래 운세를 추정하지 않는다.

## 계산

날짜와 시간 유무에 따라 인자를 구성하고 기본 결과는 읽기 쉬운 텍스트로 출력한다.

```sh
npx --yes saju8z --date 2000-02-29 --time 00:10 --format text
npx --yes saju8z --date 2000-02-29 --format text
npx --yes saju8z --date 2017-05-01 --time 12:00 --gmt=+09:00 --calendar lunar --format text
npx --yes saju8z --date 2017-05-01 --time 12:00 --gmt=+09:00 --calendar lunar --leap --format text
```

- `--time`을 생략하면 날짜 기준 삼주만 제공된다. 시간 미상 계산에는 시차 환산과 -30분 보정이 적용되지 않는다.
- CLI 오류가 나면 날짜·시간·달력 입력을 임의로 고치지 말고 오류를 간단히 설명한 뒤 필요한 값만 확인한다.
- 시간 포함 결과에는 실제 적용된 GMT 오프셋과 계산 결과의 날짜·시각을 함께 보여준다. 시간 미상 결과에는 삼주만 나왔음을 밝힌다.
- 사용자가 풀이도 요청하면 `--format prompt`로 라이브러리가 만든 계산 결과와 해석 지침을 사용한다. 해당 결과를 다시 계산하지 말고, 가능한 경향으로 설명하며 제공되지 않은 대운·세운 등은 만들지 않는다.
- 요청하지 않은 경우 풀이를 덧붙이지 않는다.

## 실행

계산이 필요할 때만 CLI를 실행한다. 날짜와 시간은 그대로 인자로 전달하고 저장하지 않는다. 먼저 `saju8z` 실행 파일이 있으면 사용하고, 없으면 위 예시처럼 `npx --yes saju8z`를 사용한다.
